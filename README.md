# نظام إدارة البرامج الشهرية

تطبيق ويب متكامل لإدارة البرامج الشهرية لجمعية الدعوة والإرشاد وتوعية الجاليات في جنوب جدة.

## الميزات الأساسية

### الشاشات

| الشاشة | الوظيفة |
|---|---|
| **لوحة التحكم** | إحصائيات البرامج، الميزانية، المستهدفين، حالة الربط مع Google Sheets |
| **تعريف البرامج** | إضافة/تعديل/حذف برامج مع احتياجاتها (مالي/عيني/مالي وعيني)، استيراد من Excel |
| **الجدول الشهري والسنوي** | تسكين البرامج (تاريخ محدد أو أيام متكررة)، تقويم شهري/سنوي بعرض نصي ملوّن حسب القسم |
| **الكشف والتصفية** | بحث وتصفية البرامج حسب النطاق (شهري/سنوي)، الجالية، الجهة — مع زر حذف لكل صف |
| **Google Sheets** | ربط ومزامنة كاملة مع Google Sheets (JSON + تبويبات تصنيفات + المجمع) |
| **التصنيفات الرئيسية** | إدارة الجاليات، تصنيفات البرامج، وحدات القياس، الأقسام، الجهات/المواقع |
| **الطباعة** | قائمة برامج مجمّعة (مع عمود عدد المرات + ملخص + توقيع)، بطاقات بدون تكرار، ملخص إداري |

### قواعد البيانات

#### التخزين المحلي
- حفظ الحالة الكاملة في `localStorage`

#### Google Sheets (قاعدة بيانات حقيقية)
- **البيانات** — JSON كامل للحالة (حفظ/تحميل)
- **الجاليات** — قائمة الجاليات
- **الوحدات** — وحدات القياس
- **الأقسام** — الأقسام
- **التصنيفات** — التصنيفات والجاليات والوحدات والأقسام
- **الجهات** — الجهات والمواقع
- **المجمع** — بيانات مجمعة لكل برنامج مع احتياجاته (جاهز للـ Pivot Table):
  - معرف_التسكينة، البرنامج، التصنيف، الفكرة، الميزانية
  - السنة، الشهر، اليوم، **التاريخ**
  - القسم، الجالية، الجهة، الموقع
  - المستهدفون، المحاضر، المنسق، ملاحظات
  - **الاحتياج، النوع (مالي/عيني)، الكمية، الوحدة، السعر، الإجمالي**
- مزامنة تلقائية كل 3 ثوانٍ بعد كل تعديل
- مزامنة تلقائية إلى المجمع كل 5 دقائق

### ميزات الطباعة

#### قائمة البرامج
- تجميع البرامج (صف واحد لكل برنامج + **عدد المرات**)
- صيغة الأيام: "الثلاثاء 2/9/16/23/30"
- ملخص سريع: عدد البرامج | إجمالي المستهدفين | الميزانية الإجمالية
- **زر استبعاد** لكل برنامج (مع زر إعادة الكل)
- توقيع ثلاثي أسفل الجدول

#### بطاقات البرامج
- بطاقة واحدة لكل برنامج (بدون تكرار) مع قائمة مواعيد التنفيذ
- شبكة 3 أعمدة للحقول
- جدول الاحتياجات مع ملخص
- توقيع: مقدم البرنامج | مدير القسم | اعتماد المدير
- زر طباعة فردي لكل بطاقة

#### ملخص الإدارة
- إحصائيات: عدد البرامج، إجمالي الميزانية، المستهدفين، الجاليات/الأقسام
- جدول مختصر بالبرامج

### الأقسام (ملوّنة)
- **القسم النسائي** — وردي
- **القسم الدعوي** — أخضر
- **قسم الجاليات** — بنفسجي

### استيراد Excel
- رفع ملف Excel مع الأعمدة: اسم البرنامج، الجالية، التاريخ، المكان، الفكرة، المستهدفون، الاحتياج، النوع، الكمية، الوحدة، السعر
- معاينة قبل الاستيراد
- استيراد دفعة واحدة مع الاحتياجات

### تقنيات مستخدمة
- HTML / CSS / JavaScript (تطبيق صفحة واحدة)
- Font: Tajawal
- localStorage للتخزين المحلي
- SheetJS (XLSX) لاستيراد/تصدير Excel
- Google Apps Script للمزامنة مع Google Sheets
